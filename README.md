### 💡 Did you know?
C still sits under most of the stack we use every day — the Linux kernel is written in it, and Unix was rewritten in C in **1973** so it could leave a single machine (the PDP-11) and run on others. C11 later added a real memory model plus `<threads.h>` and `<stdatomic.h>`, so portable multithreading is part of the language, not just a POSIX extra.
